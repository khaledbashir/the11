# 🚀 AI Command Bar - Quick Reference

## How to Use

### Basic Flow:
1. **Select text** in your document
2. **Command bar appears** automatically above your selection
3. **Start typing** your command (input is already focused!)
4. **Press Enter** to execute and replace
5. **Press Escape** to cancel

### Quick Actions (One-Click):
- **Improve Writing** - Enhances clarity and flow
- **Fix Grammar** - Corrects spelling, grammar, punctuation
- **Summarize** - Creates 2-3 sentence summary

### Keyboard Shortcuts:
- `Enter` - Execute command & replace selection
- `Shift+Enter` - Insert below (coming soon)
- `Escape` - Cancel and close command bar
- `Ctrl+Z` - Undo AI changes

## Tips:

✅ **Be specific** - "Turn into a pricing table" works better than "make a table"

✅ **One action at a time** - Execute each command separately for best results

✅ **Undo is your friend** - Don't fear experimenting - Ctrl+Z always works

✅ **Quick actions first** - Try the one-click buttons before typing custom commands
