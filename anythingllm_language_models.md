# Feature Overview: Language Models

![AnythingLLM Large Language Models](/_next/image?url=%2Fimages%2Ffeatures%2Flanguage-models%2Fheader-image.png&w=3840&q=100) 

️💡

**Tip:** Models that are multi-modal (text-to-text & image-to-text) are supported for System & Workspace models.

AnythingLLM allows you to use a host of LLM providers for chatting and generative AI.

Depending on your selection additional configuration might be required.

## Supported Language Model Providers

### Local Language Model Providers

- **Built-in (default)** - Default model included with AnythingLLM
- **Ollama** - Local LLM provider ([Website](https://ollama.com/))
- **LM Studio** - Local AI model runner ([Website](https://lmstudio.ai/))
- **Local AI** - Open-source local AI platform ([Website](https://localai.io/))

### Cloud Language Model Providers

- **OpenAI** - Leading cloud LLM provider ([Website](https://platform.openai.com/))
- **Azure OpenAI** - Microsoft's OpenAI service ([Website](https://azure.microsoft.com/en-us/products/ai-services/openai-service))
- **AWS Bedrock** - Amazon's managed AI service ([Website](https://aws.amazon.com/bedrock))
- **Anthropic** - AI safety-focused provider ([Website](https://anthropic.com/))
- **Cohere** - Enterprise-focused LLM provider ([Website](https://cohere.com/))
- **Google Gemini Pro** - Google's AI model ([Website](https://ai.google.dev/))
- **Hugging Face** - Open-source AI platform ([Website](https://huggingface.co/))
- **Together AI** - Distributed compute for AI ([Website](https://www.together.ai/))
- **OpenRouter** - Multi-model API platform ([Website](https://openrouter.ai/))
- **Perplexity AI** - Research-focused AI ([Website](https://www.perplexity.ai/))
- **Mistral API** - European AI model provider ([Website](https://mistral.ai/))
- **Groq** - High-performance AI inference ([Website](https://groq.com/))
- **KobaldCPP** - Local AI model runner ([Website](https://github.com/LostRuins/koboldcpp))
- **OpenAI (generic)** - Generic OpenAI API integration
